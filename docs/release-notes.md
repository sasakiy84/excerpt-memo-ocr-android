画像の調整画面で「元画像」「補正後」を切り替えられるようにしました。それぞれの画像を基準にトリミング・回転でき、補正後を編集しても UVDoc を重ねて実行しません。編集途中の範囲と角度は切り替え・画面回転時に保持します。

読取りの進捗に NDLOCR-Lite、PP-OCRv6 small、UVDoc の名前と、現在の処理件数を表示します。

Android 16 以上の arm64 端末向けです。`excerpt-memo-v0.5.1.apk` をインストールしてください。

UVDoc 自体の実端末での動作・速度・消費電力は引き続き未確認です。前版の [比較レポート](https://github.com/sasakiy84/excerpt-memo-ocr-android/blob/v0.5.1/docs/ocr-comparison.md) に確認範囲を記録しています。
